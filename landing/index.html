What DarkShield does

🧠 Detect

Finds dark-pattern signals in page text using model + keyword logic.

📊 Score

Assigns a manipulation score so risk is easier to compare.

🧾 Explain

Shows what each pattern means, why it matters, and examples.

How it works

1
Scan page copy
The extension/API reads candidate snippets from live pages.
2
Classify patterns
Local ONNX or API model predicts likely manipulation categories.
3
Store + visualize
SQLite + dashboard track trends by domain and vertical.
